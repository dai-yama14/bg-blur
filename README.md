# bg-blur

SAM2（Segment Anything Model 2）で人物をセグメンテーションし、背景にぼかしをかける動画編集ツールです。PyQt6 の GUI で、ポイントを打って人物を指定 → 全フレームへ伝播 → ぼかしを適用してエクスポート、という流れで使います。

## 主な機能

- **SAM2 によるトラッキング** — フレーム上をクリックするだけで人物を選択し、全フレームへ伝播
- **複数人の同時トラッキング** — 人物ごとにマスクを分けて管理
- **ポイントによる修正** — バッグなどの小物が外れたらクリックで追加し、「⟲ ポイントを反映」で前方・後方の両方へ再伝播
- **手動編集** — ブラシ / 消しゴムでフレーム単位の調整
- **Undo / Redo** — 30 操作まで遡れる変更履歴
- **プロキシ編集** — UHD/4K は FHD に縮小して編集し、エクスポート時に元解像度へ戻す
- **GPU アクセラレーション** — ぼかしと合成を PyTorch で GPU 処理（CUDA が無ければ自動で CPU）
- **長尺動画の分割処理** — 区間ごとに処理して結合（メモリ使用量を一定に抑える）
- **自動保存** — 5 分ごと、および終了時に保存。次回同じ動画を開くと復帰を提案

## 動作環境

- Python 3.10 以上（3.11 で動作確認）
- NVIDIA GPU + CUDA（CPU でも動作しますが実用的な速度が出ません）
- 開発・確認環境: RTX 5080 / CUDA 12.8 / PyTorch 2.10 / Ubuntu 24.04 (WSL2)

## セットアップ

### 1. 依存パッケージ

```bash
conda create -n vbs python=3.11
conda activate vbs
pip install torch --index-url https://download.pytorch.org/whl/cu128
pip install PyQt6 opencv-python numpy pyyaml omegaconf hydra-core
```

### 2. SAM2

```bash
git clone https://github.com/facebookresearch/sam2.git
cd sam2
pip install -e .
```

CUDA 拡張（`sam2._C`）は後処理（マスクの穴埋め）に使われます。ビルドした Python の
バージョンと実行環境が食い違うと警告が出て後処理がスキップされるため、
実行する環境の Python でビルドしてください。

### 3. チェックポイント

リポジトリには含まれていません。[SAM 2 のリポジトリ](https://github.com/facebookresearch/sam2#download-checkpoints)から取得し、`checkpoints/` に置いてください。

```
checkpoints/
├── sam2.1_hiera_large.pt
└── sam2.1_hiera_base_plus.pt
```

### 4. 作業用フォルダ

`input/` と `output/` は起動時に自動生成されます。動画を開くと `input/`、書き出すと `output/` が初期表示になります。

## 使い方

```bash
python bg-blur_1.py
```

1. 「モデルをロード」で SAM2 を読み込む
2. 「ファイル → 動画を開く」（フレーム抽出を求められたら「はい」）
3. 「＋ 追加」で人物トラックを作り、ビューポートで対象をクリック
4. 「▶ 全フレーム伝播」
5. 小物が外れていたら、そのフレームでクリックしてから「⟲ ポイントを反映」
6. 「ファイル → エクスポート」

### ショートカット

| キー | 操作 |
|---|---|
| `V` / `X` | 人物選択 / 除外ポイント |
| `B` / `E` | ブラシ / 消しゴム |
| `H` / `F` | パン / ズームリセット |
| `Space` | 再生 / 停止 |
| `←` `→` | 1 フレーム移動（`Shift` で 10 フレーム） |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Ctrl+O` / `Ctrl+S` | 動画を開く / プロジェクト保存 |

## メモリについて

SAM2 は伝播中、フレームあたり約 6MB を消費します。目安は次のとおりです。

| 動画長（30fps） | 必要メモリの目安 |
|---|---:|
| 30 秒（900 フレーム） | 約 6 GB |
| 60 秒（1800 フレーム） | 約 11 GB |
| 120 秒（3600 フレーム） | 約 22 GB |

長尺の動画は「ファイル → 分割して処理」を使うと、区間ごとに状態を作り直すため
長さによらず一定量に収まります。伝播の開始前に空きメモリを確認し、
不足しそうなら警告が出ます。

## 環境変数

| 変数 | 既定 | 説明 |
|---|---|---|
| `VBS_GPU_BLUR` | `1` | `0` でぼかし・合成の GPU 処理を無効化 |
| `QT_QPA_PLATFORM` | 自動 | WSLg では `xcb` を自動選択（Wayland ではドロップダウンが閉じない問題があるため） |

## ライセンス

SAM2 のモデルとコードは Meta の配布条件に従います。
